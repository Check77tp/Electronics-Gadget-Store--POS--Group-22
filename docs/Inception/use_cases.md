# High-Level Use Cases

*Inception deliverable — 10% (brief) use cases*

## UC01: Process Sale
**Primary Actor:** Cashier  
**Description:** The cashier scans products, the system calculates the total amount, processes payment, and prints a receipt.

## UC02: Manage Inventory
**Primary Actor:** Manager  
**Description:** The manager adds, updates, or removes products from the system.

## UC03: Generate Sales Report
**Primary Actor:** Manager  
**Description:** The manager views sales summaries and performance reports.

## UC04: Manage Users
**Primary Actor:** Admin  
**Description:** The admin creates and manages user accounts and assigns roles.

## UC05: Search Product
**Primary Actor:** Cashier  
**Description:** The cashier searches for products by name, category, or barcode.

## UC06: Print Receipt
**Primary Actor:** Cashier  
**Description:** The system generates and prints a receipt after a successful transaction.

## UC07: Process Payment
**Primary Actor:** Cashier  
**Description:** The cashier selects a payment method and confirms payment.

## UC08: Apply Discount
**Primary Actor:** Cashier  
**Description:** The cashier applies an authorized discount during checkout.
